## 🚀 Installation

```bash
git clone https://github.com/rrojas1296/nvim-2026 ~/.config/nvim
```

```bash
cd ~/.config/nvim 
```

```bash
nvim
```

## ⚡️ Requirements

- Neovim >= 0.11.0
- Node.js >= 24.12.0
- Nerd Fonts (https://www.nerdfonts.com/) recommended JetBrains Mono
- Terminal with true color support (Alacritty, Kitty, iTerm2, Gnome Terminal, and Neovim built-in terminal)
- Lazygit
- Ripgrep
